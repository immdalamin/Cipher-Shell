# Cipher-Shell


## 🛡️ Cipher-Shell: Extended Vigenère Tool 🔑
Cipher-Shell is a simple Python utility for powerful Extended Vigenère encryption and decryption. Secure your messages using a custom alphabet of 95 printable characters (letters, numbers, punctuation, and spaces) with a case-sensitive, letter-based key.

Protect your secrets with this easy-to-use, interactive command-line tool. Download and start encrypting today!
